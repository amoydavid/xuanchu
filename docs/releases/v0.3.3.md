# v0.3.3 E2E 覆盖补强

v0.3.3 是 v0.3.x 的测试可信度补丁，不新增用户可见功能。这个版本把发布前验证从“组件测试为主”补强为“真实二进制、真实 server、真实 HTTP/MCP transport、真实存储后端”的端到端覆盖。

## 变更

- 新增 Remote CLI + HTTP API 黄金路径：远程 CLI 写入 project/task 后，直接通过 HTTP API 查询同一批数据，并确认 remote mode 不写入客户端本地 DB。
- 新增 HTTP MCP 黄金路径：通过 MCP Go SDK 的 streamable HTTP transport 调用 `task_add` / `task_query`，断言 `structuredContent` 可用于机器读取。
- 新增 HTTP MCP project allowlist 失败边界：workspace 内允许的 project 可操作，越权 project 返回结构化权限错误。
- 新增 stdio MCP 黄金路径：通过真实 `xuanchu mcp stdio` 进程调用 `task_add` / `task_query`，并确认 operation log 写入文件。
- 新增真实 server dispatcher smoke：Hook delivery 和 notification delivery 在真实 server runtime 中被领取并推进状态，本地回环 endpoint 按 SSRF 防护进入 dead-letter，同时记录可排障的 operation log，且不泄露 webhook secret。
- 新增 PostgreSQL opt-in E2E：使用 `XUANCHU_E2E_POSTGRES_ADMIN_URL` 创建临时 `xuanchu_e2e_*` 数据库，覆盖 server、HTTP API、HTTP MCP Host guard、MCP tool 调用和日志字段。
- 新增 SQLite migration smoke：最小旧 schema 数据迁移后，`--json` stdout 保持纯 JSON，当前二进制仍可继续写入和查询。

## 运行方式

默认测试不依赖 PostgreSQL：

```bash
go test ./tests/integration -count=1
```

PostgreSQL E2E 需要显式提供 admin URL：

```bash
XUANCHU_E2E_POSTGRES_ADMIN_URL='postgres://mac@127.0.0.1:5432/postgres?sslmode=disable' \
  go test ./tests/integration -run TestPostgresE2E -count=1
```

该测试会自动创建并删除 `xuanchu_e2e_*` 临时数据库。默认 `go test ./...` 没有外部数据库依赖。
