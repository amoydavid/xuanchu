# Web Console 编辑体验下一轮实现计划

日期：2026-06-28

## 背景

本轮已修正基础编辑一致性：

- 关闭项目时任务列表禁写。
- 完成/删除任务时详情页写入口统一禁用或隐藏。
- 项目列表操作菜单移除无效菜单项，只保留真实打开动作。
- inline 文本/日期/逗号字段避免未变更保存、同步外部值，并改善可编辑提示。
- web test、lint、typecheck、build 均已通过。

下一轮目标不是扩大资源面，而是把 project/task 编辑从“能改字段”提升到“可放心操作”：复杂字段使用合适控件，用户能看见保存状态，移动端不丢关键能力。

## ASCII 原型

### A. 桌面任务详情编辑面板

目标：把高频编辑集中在当前任务页，复杂字段用 picker/dialog，不再依赖逗号文本输入。

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ acme / adsops / ads-23                                      [返回项目] [⋯] │
│                                                                              │
│  写投放日报  ✎                                    [开始] [完成] [删除]      │
│  整理素材表现、异常原因和下一步动作  ✎                                      │
│  [pending] [H] [ads-23]                                                       │
├──────────────────────────────────────────────┬───────────────────────────────┤
│ 注解                                         │ 属性                          │
│ ┌──────────────────────────────────────────┐ │ 状态        pending            │
│ │ 需要补充截图                             │ │ 优先级      [ H        v ]     │
│ │ 2026-06-28  alice              [✎] [🗑] │ │ 截止        [2026-07-03]       │
│ └──────────────────────────────────────────┘ │ 负责人      [alice x] [+]      │
│ [记录进展、背景或决策...] [添加注解]         │ 标签        [ads x] [daily x]+ │
│                                              │ 依赖        [ads-12 x] [+]     │
│ 链接                                         │ 等待到      [ yyyy-mm-dd ]      │
│ ┌──────────────────────────────────────────┐ │ 计划        [ yyyy-mm-dd ]      │
│ │ 规格文档 · spec · alice       [✎] [🗑]  │ │ 重复        [ -        ✎ ]      │
│ └──────────────────────────────────────────┘ │ 自定义字段                    │
│ [添加链接]                                   │ channel     [ meta     ✎ ]     │
└──────────────────────────────────────────────┴───────────────────────────────┘
```

交互要点：

- 标题/描述继续 inline 编辑，但长文本失败时保留输入框和草稿。
- 负责人、标签、依赖以 chip 表示当前值，`+` 打开选择器。
- 链接/注解每行提供编辑和删除图标，编辑走 dialog。
- 任务完成或删除后，右侧属性和左侧新增/编辑入口统一禁用或隐藏。

### B. 保存反馈与错误提示

目标：反馈不打断操作，但用户能明确知道保存结果。

```text
┌──────────────────────────────────────────────────────────────┐
│ 写投放日报  ✎                                                │
│                                                              │
│                              ┌────────────────────────────┐  │
│                              │ ✓ 已保存：任务标题         │  │
│                              └────────────────────────────┘  │
└──────────────────────────────────────────────────────────────┘

失败态：

┌──────────────────────────────────────────────────────────────┐
│ [写投放日报                                  ]               │
│ 保存失败：permission_denied                                  │
│                                            [重试] [取消]      │
└──────────────────────────────────────────────────────────────┘
```

交互要点：

- 成功反馈默认 2-3 秒自动消失。
- 失败反馈贴近当前编辑控件，不丢草稿。
- 批量页面级操作（创建、删除、状态变更）走右上角 toast；字段级错误走行内提示。

### C. 负责人选择器

目标：从“记住 user id/email”改为“搜索并选择人”。

```text
负责人
┌──────────────────────────────────────────────┐
│ [alice x] [bob x] [+]                         │
└──────────────────────────────────────────────┘

点击 [+] 后：

┌──────────────────────────────────────────────┐
│ 搜索负责人                                   │
│ [ ali                                      ] │
├──────────────────────────────────────────────┤
│ ✓ Alice Zhang      alice@example.com          │
│   Alicia Chen      alicia@example.com         │
│   Ali Ops          ali.ops@example.com        │
├──────────────────────────────────────────────┤
│ [清空负责人]                         [完成] │
└──────────────────────────────────────────────┘
```

交互要点：

- 搜索结果显示姓名和邮箱。
- 已选用户左侧显示勾选状态。
- 清空负责人提交 `clear_assignees`。
- 选择器关闭前可以连续选择多人，避免每选一次就触发请求。

### D. 依赖任务选择器

目标：从逗号文本框改为任务搜索、多选和 chip。

```text
依赖
┌──────────────────────────────────────────────┐
│ [ads-12 素材审核 x] [ads-18 预算确认 x] [+]  │
└──────────────────────────────────────────────┘

点击 [+] 后：

┌──────────────────────────────────────────────┐
│ 搜索依赖任务                                 │
│ [ 素材                                    ] │
├──────────────────────────────────────────────┤
│ ✓ ads-12  素材审核              pending      │
│   ads-19  素材二审              active       │
│   ads-31  素材归档              completed    │
├──────────────────────────────────────────────┤
│ [清空依赖]                           [完成] │
└──────────────────────────────────────────────┘
```

交互要点：

- 搜索范围默认为当前项目任务。
- 每个候选显示 `task_slug + title + status`。
- 已完成任务可被选择，但用状态弱化展示；如后端禁止，前端显示错误。
- 清空依赖提交 `clear_depends`。

### E. 链接编辑 dialog

目标：链接写错时可直接编辑，不必删除重建。

```text
┌──────────────────────────────────────────────┐
│ 编辑链接                                      │
├──────────────────────────────────────────────┤
│ 类型                                         │
│ [ spec                                    ]  │
│ URL                                          │
│ [ https://example.com/spec                ]  │
│ 标题                                         │
│ [ 投放规格文档                            ]  │
├──────────────────────────────────────────────┤
│                              [取消] [保存链接]│
└──────────────────────────────────────────────┘
```

交互要点：

- 新增和编辑复用同一个表单组件。
- URL 继续只接受 `http` / `https`。
- 保存失败不关闭 dialog。

### F. 注解编辑 dialog

目标：注解允许补充和修正，保留删除确认。

```text
┌──────────────────────────────────────────────┐
│ 编辑注解                                      │
├──────────────────────────────────────────────┤
│ [需要补充截图，并确认昨天预算变化。          ]│
│ [                                            ]│
│ [                                            ]│
├──────────────────────────────────────────────┤
│                              [取消] [保存注解]│
└──────────────────────────────────────────────┘
```

交互要点：

- 注解内容为空时禁止保存。
- 保存失败不关闭 dialog。
- 删除仍使用 destructive confirm。

### G. 移动端任务卡

目标：手机上能完成常见 triage，不强制进入详情页。

```text
┌────────────────────────────────────┐
│ ads-23                      pending │
│ 写投放日报 ✎                       │
│                                    │
│ [H v]   [2026-07-03]               │
│ alice · ads,daily                  │
│                                    │
│ [开始] [完成] [⋯]                  │
└────────────────────────────────────┘

点击 [⋯]：

┌──────────────────────┐
│ 打开详情             │
│ 复制任务链接         │
│ 删除任务             │
└──────────────────────┘
```

交互要点：

- 移动端直接支持标题、优先级、截止日期编辑。
- 复杂字段仍进入详情页处理。
- 操作按钮保持单行或自动换行，不允许文本溢出。

## 范围

### 1. 保存反馈与错误模型

目标：让所有编辑动作有一致反馈。

任务：

- 增加轻量 toast 或页面级 mutation feedback 组件。
- inline 保存成功显示短暂“已保存”，失败保留编辑态并显示错误。
- 删除、状态变更、创建任务、添加链接/注解统一使用同一反馈模式。
- 复制链接从永久文案改为短暂状态，避免页面堆积。

验收：

- 用户能区分“正在保存 / 已保存 / 保存失败”。
- 失败不会丢草稿。
- 不增加全局噪音，反馈在 2-3 秒后自动消失。

### 2. 负责人选择器

目标：替代负责人逗号文本框。

任务：

- 新增 `AssigneePicker`，复用 `/api/v1/users` 或现有 users API。
- 支持搜索、多人选择、清空。
- 选中项显示 name/email，提交值使用稳定 user ref。
- 在任务详情属性面板接入。

验收：

- 不需要用户记 user id。
- 当前负责人能正确预填。
- 清空负责人走 `clear_assignees`。

### 3. 依赖任务选择器

目标：替代依赖逗号文本框。

任务：

- 新增 `TaskDependencyPicker` 的搜索模式。
- 搜索当前项目任务，显示 task_slug + title + status。
- 支持多选、移除、清空。
- 已选依赖使用 chip 展示，避免误删。

验收：

- 不需要手输 UUID/task slug。
- 当前依赖能正确预填。
- 清空依赖走 `clear_depends`。

### 4. 链接与注解编辑

目标：避免“写错只能删掉重建”。

任务：

- 链接列表增加编辑入口，可修改 type/url/title。
- 注解列表增加编辑入口，可修改 description。
- 如后端暂缺 PATCH API，先补 API；前端不做假编辑。
- 删除仍保留确认弹窗。

验收：

- 链接/注解支持新增、编辑、删除完整闭环。
- 编辑失败不关闭 dialog，不丢草稿。

### 5. 移动端编辑补齐

目标：移动端不只能“打开详情页”。

任务：

- 任务卡支持标题 inline 编辑、优先级选择、截止日期编辑。
- 保留“详情页编辑更多字段”的引导，但不阻断高频操作。
- 操作按钮尺寸和文本在窄屏不溢出。

验收：

- 手机宽度下可完成常见任务 triage：改标题、优先级、截止、开始/完成。
- Playwright 或组件测试覆盖移动布局关键元素。

## 实施顺序

1. 保存反馈基础设施。
2. 负责人选择器。
3. 依赖任务选择器。
4. 链接/注解编辑。
5. 移动端任务卡编辑补齐。

每一步都先补测试，再实现；每步完成后跑：

```bash
pnpm --dir web test
pnpm --dir web lint
pnpm --dir web typecheck
pnpm --dir web build
git diff --check
```

## 暂不纳入

- 批量编辑。
- 拖拽排序或看板视图。
- 富文本编辑器。
- 新增项目级成员管理入口。
