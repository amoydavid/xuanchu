# Xuanchu v0.4.0 Web Admin Console Implementation Plan

> **For agentic workers:** REQUIRED: Use `superpowers:subagent-driven-development` (if subagents available) or `superpowers:executing-plans` to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在保持单一 `xuanchu` 二进制发布的前提下，新增嵌入式 Web Admin Console，并用 React + Vite 8.x + shadcn/ui + pnpm 实现运维入口。

**Architecture:** Go server 继续作为唯一运行时：`/api/v1/*` 和 `/mcp` 保持现有语义，新增 `/console` 只负责静态资源和 SPA fallback。Console 前端通过现有 HTTP API 读写数据，少量缺口补成通用 API；业务规则仍在 `internal/app`，前端和 `internal/webconsole` 不访问 storage。前端源码在 `web`，Vite build 直接输出到 `internal/webconsole/dist`，该目录提交并通过 Go `embed` 打入二进制；开发态由 Vite proxy 转发 `/api/v1/*` 到本地 `xuanchu server`。

**Tech Stack:** Go 1.25、`net/http`、`go:embed`、chi、React、Vite 8.x、TypeScript、pnpm、shadcn/ui、Tailwind、TanStack Query、i18next、react-i18next、lucide-react、Vitest、Playwright smoke、Node.js `20.19+` 或 `22.12+`（前端开发/构建期）、`CGO_ENABLED=0`。

`vite.config.ts`：

```ts
import react from "@vitejs/plugin-react"
import path from "node:path"
import { defineConfig, loadEnv } from "vite"

export default defineConfig(({ mode }) => {
  const env = loadEnv(mode, process.cwd(), "")
  const apiTarget = env.VITE_XUANCHU_API_TARGET || "http://127.0.0.1:8080"
  const consoleBase = env.VITE_XUANCHU_CONSOLE_BASE || "/console/"
  const normalizedConsoleBase = consoleBase.endsWith("/") ? consoleBase : `${consoleBase}/`

  return {
    base: normalizedConsoleBase,
    plugins: [react()],
    resolve: {
      alias: {
        "@": path.resolve(__dirname, "./src"),
      },
    },
    server: {
      port: 5173,
      strictPort: true,
      open: normalizedConsoleBase,
      proxy: {
        "/api/v1": {
          target: apiTarget,
          changeOrigin: true,
          timeout: 30000,
        },
      },
    },
    build: {
      outDir: "../internal/webconsole/dist",
      emptyOutDir: true,
    },
    test: {
      environment: "jsdom",
      globals: true,
    },
  }
})
```

开发态只代理 `/api/v1/*`。不要把 `/mcp` 加入 Vite proxy；Console 不通过 MCP 调用后端。默认发布使用 `/console/`；如果实现 `--console-base-path /admin` 这类自定义路径，必须用 `VITE_XUANCHU_CONSOLE_BASE=/admin/ pnpm build` 重新生成 `internal/webconsole/dist`，并保证 Go config 的 `base_path` 与该值一致。

export type SupportedLanguage = (typeof supportedLanguages)[number]

export function normalizeLanguage(value: string | undefined | null): SupportedLanguage {
  if (!value) return "zh-CN"

  if (normalized.startsWith("en")) return "en-US"

- [ ] **Step 5: 实现 ThemeProvider**

`web/src/theme.tsx`：

```tsx
import { createContext, useContext, useEffect, useMemo, useState } from "react"

export type ThemeMode = "light" | "dark" | "system"

type ThemeContextValue = {
  theme: ThemeMode
  resolvedTheme: "light" | "dark"
  setTheme: (theme: ThemeMode) => void
}

const ThemeContext = createContext<ThemeContextValue | null>(null)
const storageKey = "xuanchu.console.theme"

export function ThemeProvider({ children }: { children: React.ReactNode }) {
  const [theme, setThemeState] = useState<ThemeMode>(() => {
    const stored = localStorage.getItem(storageKey)
    return stored === "light" || stored === "dark" || stored === "system" ? stored : "system"
  })
  const [systemDark, setSystemDark] = useState(() => window.matchMedia("(prefers-color-scheme: dark)").matches)

  useEffect(() => {
    const query = window.matchMedia("(prefers-color-scheme: dark)")
    const listener = () => setSystemDark(query.matches)
    query.addEventListener("change", listener)
    return () => query.removeEventListener("change", listener)
  }, [])

  const resolvedTheme = theme === "system" ? (systemDark ? "dark" : "light") : theme

  useEffect(() => {
    document.documentElement.classList.toggle("dark", resolvedTheme === "dark")
    document.documentElement.style.colorScheme = resolvedTheme
  }, [resolvedTheme])

  const value = useMemo<ThemeContextValue>(() => ({
    theme,
    resolvedTheme,
    setTheme: (next) => {
      localStorage.setItem(storageKey, next)
      setThemeState(next)
    },
  }), [theme, resolvedTheme])

  return <ThemeContext.Provider value={value}>{children}</ThemeContext.Provider>
}

export function useTheme() {
  const value = useContext(ThemeContext)
  if (!value) throw new Error("useTheme must be used inside ThemeProvider")
  return value
}
```

`web/src/main.tsx` 需要用 `ThemeProvider` 包裹 App。
