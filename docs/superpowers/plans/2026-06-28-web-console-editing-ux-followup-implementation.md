# Web Console 编辑体验第三轮实现计划

日期：2026-06-28

## 背景

本轮已完成 project/task 编辑体验的关键闭环：

- 字段保存有统一短反馈，字段级失败保留草稿。
- 负责人和依赖任务改为可搜索选择器。
- 链接和注解支持新增、编辑、删除，且后端提供真实 PATCH API。
- 移动端任务卡支持标题、优先级、截止日期编辑。

下一轮不继续扩大到看板、拖拽或批量编辑，而是补齐“编辑密度、可发现性、复杂字段正确控件、移动端视觉验收”这些会直接影响日常使用质量的部分。

## ASCII 原型

### A. 标签选择器

目标：替代标签逗号输入，避免误删和拼写漂移。

```text
标签
+------------------------------------------------+
| [ads x] [daily x] [+]                           |
+------------------------------------------------+

点击 [+] 后：

+------------------------------------------------+
| 搜索标签                                        |
| [ da                                           ] |
+------------------------------------------------+
| ✓ daily                         23 tasks        |
|   dashboard                      7 tasks        |
|   data                           4 tasks        |
+------------------------------------------------+
| [新建标签: da]                         [完成]  |
+------------------------------------------------+
```

### B. 自定义字段编辑器

目标：UDA 不再全部用文本框；按字段类型选择合适控件。

```text
自定义字段
+----------------------+-------------------------+
| channel              | [ meta              v ] |
| budget               | [ 1200              ]   |
| reviewed             | [x]                     |
| launch_date          | [2026-07-03]            |
+----------------------+-------------------------+
```

### C. 编辑失败汇总

目标：字段旁仍显示错误，但页面顶部能看到最近失败，方便连续编辑时定位。

```text
+--------------------------------------------------------------+
| 2 个编辑未保存                                               |
| - 负责人：permission_denied                         [重试]   |
| - 链接 URL：link_duplicate                          [查看]   |
+--------------------------------------------------------------+
```

### D. 移动端任务详情骨架

目标：详情页在手机上优先显示可编辑核心字段，不让属性面板沉到底部后失去上下文。

```text
+--------------------------------------+
| acme / adsops / ads-23        [返回] |
| 写投放日报 ✎                         |
| 整理素材表现 ✎                       |
| [pending] [H]                        |
+--------------------------------------+
| [属性] [注解] [链接]                 |
+--------------------------------------+
| 优先级       [H v]                   |
| 截止         [2026-07-03]            |
| 负责人       [alice x] [+]           |
| 标签         [ads x] [+]             |
+--------------------------------------+
```

## 范围

### 1. 标签选择器

任务：

- 新增 `TagPicker`，替代任务详情里的标签逗号输入。
- 候选来源优先使用当前项目任务已有标签，必要时允许输入新标签。
- 支持搜索、多选、移除、清空。

验收：

- 标签不需要手输逗号。
- 删除单个标签不会误清空全部标签。
- 清空标签提交 `tags: []`。

### 2. UDA 类型化编辑

任务：

- 读取已有 UDA 定义或任务字段值推断最小类型。
- `date` 用日期控件，`number` 用数字输入，`boolean` 用 checkbox，其余保留 inline text。
- 保存仍复用 `modifyTask({ udas })`。

验收：

- 日期和数字不会因为字符串格式错误产生隐性坏数据。
- 未识别类型保持现状，不阻塞编辑。

### 3. 编辑失败汇总

任务：

- 扩展当前 `EditFeedbackProvider`，记录最近失败项。
- 字段级错误仍留在控件旁；页面级只显示可定位摘要。
- 支持关闭单条失败，避免长期堆积。

验收：

- 连续编辑多个字段时，用户能看到哪些保存失败。
- 成功保存不会制造页面噪音。

### 4. 移动端任务详情 tabs

任务：

- 手机宽度下把任务详情拆成 `属性 / 注解 / 链接` tabs。
- 桌面布局保持当前左右栏。
- tabs 内组件复用现有编辑器，不复制业务逻辑。

验收：

- 375px 宽度下核心字段首屏可见。
- 注解和链接编辑入口不挤压标题区域。

### 5. 浏览器级视觉和交互验收

任务：

- 用 Playwright 覆盖项目页、任务详情页、移动任务卡三个视口。
- 检查 dialog、toast、picker 在桌面和移动端不遮挡关键内容。
- 补一个链接/注解编辑的真实交互 smoke。

验收：

- 桌面和移动截图无明显溢出、重叠、空白。
- 选择器和 dialog 可通过键盘基础操作。

## 实施顺序

1. 标签选择器。
2. UDA 类型化编辑。
3. 编辑失败汇总。
4. 移动端详情 tabs。
5. Playwright 视觉与交互验收。
