# Xuanchu v0.3.3 E2E 覆盖补强 Implementation Plan

> **For agentic workers:** REQUIRED: Use `superpowers:subagent-driven-development` (if subagents available) or `superpowers:executing-plans` to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立覆盖 CLI、Remote CLI、HTTP API、HTTP MCP、stdio MCP、runtime dispatcher、PostgreSQL 和迁移 smoke 的端到端测试矩阵。

**Architecture:** 默认 E2E 继续使用 SQLite 和本地进程，保持 `go test ./...` 无外部依赖；PostgreSQL E2E 通过 `XUANCHU_E2E_POSTGRES_ADMIN_URL` opt-in。新增测试尽量放在 `tests/integration`，复用真实二进制和真实 server helper；组件内已有测试只保留，不作为发布 E2E 矩阵的唯一依据。

**Tech Stack:** Go 1.25、`testing`、`os/exec`、`net/http`、MCP Go SDK、PostgreSQL、现有 `tests/integration` helper、`CGO_ENABLED=0`。

## Chunk 2: Remote CLI + HTTP API 黄金路径

### Task 2: 真实 server 上验证 remote CLI/API 一致性

**Files:**

- [ ] **Step 1: 写测试骨架**

新增：

```go
func TestE2ERemoteCLIAndHTTPAPIGoldenPath(t *testing.T)
```

流程：

1. 构建真实 `xuanchu`。
2. 创建 server DB 和独立 client DB。
3. 在 server DB 上创建 token，scope 用 `*`。
4. 启动真实 server。
5. 用 remote CLI `--server <baseURL> --token <token>` 创建 project 和 task。
6. 用 HTTP API `/api/v1/tasks`、`/api/v1/projects` 查询。
7. 用 client 本地 DB 执行 `list`，确认远程操作没有写入 client DB。

- [ ] **Step 2: 添加断言**

断言：

- remote CLI 输出包含创建的 task/project。
- HTTP API 返回同一条 task/project。
- client DB 的本地 `list` 不包含远程 task。
- operation log 至少包含 `http_request` 和 token actor 信息。

- [ ] **Step 3: 运行测试**

Run:


## Chunk 6: PostgreSQL opt-in E2E

### Task 6: 创建临时 PostgreSQL 数据库 helper

**Files:**
- Create: `tests/integration/postgres_e2e_test.go`

- [ ] **Step 1: 写环境变量 helper**

```go
func postgresE2EAdminURL(t *testing.T) string {
	t.Helper()
	url := os.Getenv("XUANCHU_E2E_POSTGRES_ADMIN_URL")
	if strings.TrimSpace(url) == "" {
		t.Skip("XUANCHU_E2E_POSTGRES_ADMIN_URL not set")
	}
	return url
}
```

- [ ] **Step 2: 写临时库 helper**

实现：

```go
func createPostgresE2EDatabase(t *testing.T, adminURL string) string
```

要求：

- database name 使用 `xuanchu_e2e_<unix>_<pid>`。
- 用 Go SQL driver 或 `psql` 执行 `CREATE DATABASE` / `DROP DATABASE`。
- 返回被测 DB URL，替换 admin URL path 为临时库名。
- `t.Cleanup` 中断开连接后 `DROP DATABASE IF EXISTS`。
