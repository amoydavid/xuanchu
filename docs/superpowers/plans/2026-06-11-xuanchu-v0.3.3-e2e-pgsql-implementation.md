**Files:**

- [ ] **Step 1: 写跳过测试**

新增 helper：

```go
func postgresE2EAdminURL(t *testing.T) string {
	t.Helper()
	url := os.Getenv("XUANCHU_E2E_POSTGRES_ADMIN_URL")
	if strings.TrimSpace(url) == "" {
		t.Skip("XUANCHU_E2E_POSTGRES_ADMIN_URL not set")
	}
	return url
}
```

- [ ] **Step 2: 写临时库创建 helper**

实现：

```go
func createPostgresE2EDatabase(t *testing.T, adminURL string) string
```

要求：

- database name 使用 `xuanchu_e2e_<unix>_<pid>`。
- 用 `psql` 或 Go SQL driver 执行 `CREATE DATABASE` / `DROP DATABASE`。
- 返回被测 DB URL，替换 admin URL path 为临时库名。
- `t.Cleanup` 中强制断开该库连接后 `DROP DATABASE IF EXISTS`。

## Chunk 2: 真实 server + pgsql smoke

### Task 2: 覆盖 PostgreSQL server/log/HTTP 流程

**Files:**
- Modify: `tests/integration/postgres_e2e_test.go`

- [ ] **Step 1: 写 E2E 测试骨架**

新增：

```go
func TestPostgresE2EServerLogsAndHTTP(t *testing.T)
```

流程：

1. `adminURL := postgresE2EAdminURL(t)`
2. `dbURL := createPostgresE2EDatabase(t, adminURL)`
3. `bin := buildXuanchu(t)`
4. 写临时 `xuanchu.toml`，包含 `[log.file] path` 和 `[server.mcp] trusted_proxy_hosts = ["xuanchu.example.com"]`
5. 用 `--db-url dbURL --json --workspace local token create http-e2e --scope '*'` 创建 token
6. 启动 `xuanchu --config config --db-url dbURL server --listen <free addr>`
7. 请求 `/healthz` 和 `/api/v1/me`
8. 停止 server 后读取日志文件

- [ ] **Step 2: 添加断言**

断言：

- token JSON 中 `token` 以 `xuanchu_pat_` 开头。
- `/healthz` 返回 200。
- `/api/v1/me` 返回 200。
- 日志包含 `operation=server_listening`、`operation=http_request`、`operation=shutdown_signal`。
- 日志包含 `workspace_id=` 和 `workspace_ref=local`。

- [ ] **Step 3: 运行 PostgreSQL E2E**

Run:

```bash
XUANCHU_E2E_POSTGRES_ADMIN_URL='postgres://mac@127.0.0.1:5432/postgres?sslmode=disable' \
  go test ./tests/integration -run TestPostgresE2EServerLogsAndHTTP -count=1
```

Expected: PASS，并清理临时数据库。

## Chunk 3: HTTP MCP Host allowlist E2E

### Task 3: 在真实 server 上验证 MCP Host guard

**Files:**
- Modify: `tests/integration/postgres_e2e_test.go`

- [ ] **Step 1: 扩展 E2E 测试**

在同一个 server 流程里新增两个 `/mcp` 请求：

- `Host: evil.example.com`，带合法 Bearer token，期望 403。
- `Host: xuanchu.example.com`，不带 Bearer token，期望 401。

这样能证明：

- 未信任 Host 被自定义 guard 拒绝。
- 可信 Host 能通过 Host guard 到达 auth middleware。
